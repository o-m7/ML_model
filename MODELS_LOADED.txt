SIGNAL ENSEMBLE VOTING:
════════════════════════════════════════════════════════════════════════════════

Strategy:
  1. Each model generates prediction (BUY/SELL/NEUTRAL)
  2. Aggregate votes: majority rules
  3. Confidence = average of model confidence scores
  4. Final Signal = Vote + Confidence

Example (5T live signal):
  - Model A: BUY (0.75 confidence)
  - Model B: BUY (0.82 confidence)
  - Model C: NEUTRAL (0.55 confidence)
  
  → FINAL: 🟢 BUY at 0.71 average confidence
